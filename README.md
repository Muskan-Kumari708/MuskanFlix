# MuskanFlix 🎬

A Netflix-inspired developer portfolio showcasing my projects, skills, and experience.

🔗 **Live Demo:** Add your live website link here.

## Features

- Netflix-style UI with project cards
- Fully responsive design
- Smooth hover effects and navigation
- Sections for projects, skills, and contact

## Tech Stack

- React.js
- JavaScript (ES6+)
- Vite
- Tailwind CSS
- GSAP (including ScrollTrigger)
- Framer Motion

## Run Locally

1. Clone the repository:

   ```bash
   git clone https://github.com/Muskan-Kumari708/muskanflix.git
   ```

2. Go to the project folder:

   ```bash
   cd muskanflix
   ```

3. Install dependencies:

   ```bash
   npm install
   ```

4. Start the project:

   ```bash
   npm run dev
   ```
